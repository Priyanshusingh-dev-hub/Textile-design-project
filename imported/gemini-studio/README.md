# Earlier LoomLab Studio pieces

These files came from the `gemini-work` repository. They are not wired into
the LoomLab app in `backend/` and `frontend/`.

That repository was an earlier studio: a smaller colour engine, a second
React workspace, and a slightly older copy of
`TextileAI_Hybrid_Separation_Lab_v1_3`. The lab and the live app in this
repository are the copies to use. What is kept here is only the code that
did not already exist: design notes, a small region filler, halftone,
repeat tiling, project save, and the studio panels.
